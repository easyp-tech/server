<objective>
Rewrite `commitUUID` in `internal/connect/commits_helpers.go` to derive a 16-byte UUID from the first 14 bytes of the git SHA plus fixed UUID version/variant bits, with a strict 40-hex-char input contract. Update the existing test file with the new expected values and add four new test cases (known SHA, invalid input, inverse recovery, short-SHA pre-resolve) per D-13.

Purpose: This is the core behavioral change for Phase 16. The proxy stops minting commit IDs by SHA-256-hashing the git SHA and instead reuses the first 14 SHA bytes directly. Call sites in `commits.go` are updated in plan 16-02; this plan only ships the helper and its tests.

Output: A new `commitUUID` function (signature `(string, error)`), a `preResolveForTest` test fixture that pads any string to 40 hex chars, and a passing test file.
</objective>
